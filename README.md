# Bullshit Corner

Web app for [bscorner.com](https://bscorner.com).

## Stack

TanStack Start, React, Convex, Tailwind CSS v4, shadcn/ui.

## Develop

```bash
pnpm install
pnpm dev
```

App runs on http://localhost:3000 (falls back to the next free port). Convex syncs in parallel via `convex dev`.
